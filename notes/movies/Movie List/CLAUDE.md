# CLAUDE Movie Format

Each movie is stored as a Markdown file named after the movie title. Only include multiple language names in the filename when relevant, separated by '/'.

## Metadata

At the top of each file, include key metadata in a structured format. This is an example list - you can include more or fewer fields as needed:

- **Title:** [Movie Title]
- **Year:** [Release Year]
- **Director:** [Director Name]
- **Main Actor:** [Main Actor Name]
- **Genre:** [Genres]
- **Added Reasons:** [Why it was added to this movie list - can have multiple reasons]
- **Previously Seen By:** [Who has seen it before and rough time - e.g., "Me (2020), John (2022)"]
- **Tags:** [Custom tags with timestamps when added - e.g., "not interested (2026-03-14)", "must-watch (2026-03-15)"]

## Optional Sections

You can add other sections as needed, such as:

- Overview
- Plot Summary
- Reviews
- etc.

## Comments Section

At the end of the file, include a **Comments** section for personal notes and discussions.

Each comment should follow this format:

### [Very Brief Title]

**Timestamp:** [Date and Time, e.g., 2026-03-14 10:30 AM]

[Comment content here]
