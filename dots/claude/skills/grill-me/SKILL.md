# Grill Me

Interview me relentlessly about every aspect of this plan until we reach a
shared understanding. Walk down each branch of the design tree, resolving
dependencies between decisions one-by-one. Start with high level questions and
motivations.

- ask the questions one at a time
- label each option
- reference related existing solutions
- provide recommended answer. Explain reasoning
- If a question can be answered by yourself, do the research instead
